- **Do** use for detail views, filters and edit forms that need more room than a dialog, while the page behind stays in view
- **Do** open it from the `end` edge for details and editing, and from the `start` edge for filters or navigation that sits on that side of the page
- **Do** put action buttons in `RudiDrawer.Footer`, primary action last; it stays visible while long content scrolls
- **Do** set `closeLabel` when your interface isn't in English. It names the close button.
- **Don't** use for short confirmations. Use **Dialog** instead.
- **Don't** use for an app's main navigation. `RudiAppShell` already turns its sidebar into a drawer on narrow screens.
- **Don't** open a dialog or a second drawer from a drawer. Keep the task in one panel.
