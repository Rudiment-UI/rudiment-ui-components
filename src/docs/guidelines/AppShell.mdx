- **Do** render one `RudiAppShell` per page, with `RudiAppShell.Sidebar` for navigation and `RudiAppShell.Main` for the page body, so the page gets `aside` and `main` landmarks
- **Do** put `RudiAppShell.MenuButton` in the top bar: it only shows below 900px, opens the sidebar as a drawer, and reports `aria-expanded`
- **Do** control the drawer (`isSidebarOpen` / `onSidebarOpenChange`) when you need to close it after navigation
- **Don't** nest `RudiAppShell`, or put page content in the sidebar
