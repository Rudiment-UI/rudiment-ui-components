# Components

Components are grouped by what they do. Each page shows the component's examples, props, design tokens, and usage guidelines. [Guidelines](?path=/docs/components-guidelines--docs) collects the usage guidance for every component on one page.

Layout primitives such as Stack and Grid are under [Layouts](?path=/docs/layouts-overview--docs). Heading, Text, and Prose are under [Typography](?path=/docs/typography-overview--docs).
